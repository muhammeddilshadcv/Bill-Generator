# 🧾 Bill Generator

A simple and lightweight Python-based bill generator system designed to help small businesses or rental services quickly generate itemized invoices. Built using `tkinter` for the GUI and `fpdf` for PDF bill generation.

---

## 🚀 Features

- ✅ Easy-to-use graphical interface
- 🧮 Itemized bill entry with quantity and price
- 🖨️ Generates clean, professional-looking PDF invoices
- 🧾 Calculates subtotal and grand total automatically
- 🗃️ Resets and clears fields after bill generation

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/muhammeddilshadcv/Bill-Generator.git
cd Bill-Generator
```

### 2. Install dependencies
```
pip install fpdf
```

### 3. Run the application
```
python main.py
```
